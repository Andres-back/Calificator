# Contrato de interfaz

## ActionMenu

- Recibe una etiqueta accesible y una lista ordenada de acciones.
- Cada acción define etiqueta, icono opcional, enlace o callback y tono opcional.
- Cierra al ejecutar, pulsar Escape o pulsar fuera.

## CollectionToolbar

- Recibe consulta, contador, opciones y filtro activo.
- Emite cambios de consulta y categoría sin efectos de red propios.

## Button

- Conserva las variantes existentes.
- Añade tamaño `xl`, icono opcional y ancho completo opcional.
