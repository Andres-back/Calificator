# Datos: respuesta visual

No hay migración. La evidencia JSON existente agrega a cada respuesta extraída una descripción visual opcional de los trazos del estudiante. Se conservan pregunta, página, páginas de origen, texto, confianza, legibilidad y revisión. Las evidencias antiguas sin ese atributo siguen siendo válidas.

Una descripción visual incierta se representa como ausencia de descripción junto a revisión obligatoria, no como prueba de respuesta en blanco. La calificación vigente y el historial no se alteran.
