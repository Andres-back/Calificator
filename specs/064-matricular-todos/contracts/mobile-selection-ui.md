# Contrato de interfaz: selección de estudiantes existentes

- El control visible se llama “Todos”.
- Su nombre accesible comunica si seleccionará o desmarcará los resultados visibles.
- Está deshabilitado durante carga, sin resultados o mientras se confirma la matrícula.
- No envía solicitudes por sí mismo.
- El botón “Matricular N” sigue siendo la única confirmación que persiste matrículas.
- Las casillas individuales continúan disponibles.
