# Datos: arbitraje no redundante

No se crean ni modifican entidades, columnas o contratos públicos. Se conservan una entrega, una calificación vigente y un trabajo asíncrono. La salida existente registra `strategy.arbiter_invoked` y `strategy.arbiter_reason`; las alertas y el desglose continúan en la calificación pendiente de revisión docente.
