# Modelo compatible
ExtractedAnswer: texto/dibujo, fuentes, legibilidad, blanco y revisión; añadir partial=False compatible con JSON anterior. Una respuesta parcial conserva texto leído y requiere revisión.
VisionPageResult: rol reading/responses/mixed/unknown (por defecto unknown). Preguntas ausentes pueden omitirse; no se declaran respondidas.
VisionExtraction conserva páginas terminadas y fallidas con cobertura explícita. Entrega/Calificacion no cambian esquema; reanálisis mantiene evidencia/historial y no toca decisiones docentes.
