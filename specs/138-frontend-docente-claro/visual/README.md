# Evidencia visual verificada

Capturas reales del frontend implementado con fixtures sintéticos. No contienen estudiantes reales ni acreditan pruebas físicas de teléfonos. La maqueta previa está separada de estas capturas.

- [Celular 384 px, claro](revision-384-light-chromium.png)
- [Celular 384 px, oscuro](revision-384-dark-chromium.png)
- [Escritorio 1440 px, claro](revision-1440-light-chromium.png)
- [Escritorio 1440 px, oscuro](revision-1440-dark-chromium.png)
- [Edición con texto al 200 % y altura de 550 px](texto200-390-chromium.png)

Comprobaciones: una ubicación visible, una flecha de regreso, pregunta seleccionada identificable, respuesta/puntaje/razón, ausencia de texto técnico repetido, foco visible, sin desbordamiento global y acciones alcanzables. La barra pasa a flujo normal cuando fijarla taparía la lectura. Las pruebas de Chromium/WebKit complementan esta inspección; los resultados están en [quickstart.md](../quickstart.md).
