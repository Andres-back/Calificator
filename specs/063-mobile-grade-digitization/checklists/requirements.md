# Lista de calidad de requisitos

- [x] El incidente móvil tiene pasos y resultados observables.
- [x] La separación entre respuesta estudiantil y clave correcta está definida explícitamente.
- [x] Se conserva la revisión humana de claves y calificaciones.
- [x] Los criterios de éxito son medibles en móvil y en pruebas automatizadas.
- [x] Se excluye la modificación automática de evaluaciones históricas.
- [x] No quedan marcadores de aclaración ni decisiones funcionales abiertas.
