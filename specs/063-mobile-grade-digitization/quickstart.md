# Validación rápida

1. Ejecutar las pruebas unitarias focalizadas de digitalización.
2. Ejecutar las pruebas del selector de carga y buscador de revisión.
3. Abrir el centro de calificación a 360×800.
4. Escribir rápidamente un nombre y comprobar que el campo no se bloquea y que la lista no parpadea.
5. Abrir “Añadir entregas”, buscar y seleccionar un estudiante.
6. Verificar una estructura con `270 × 67` y clave propuesta `18.760`; debe quedar `18.090` con advertencia.
7. Confirmar que no existe migración ni escritura sobre evaluaciones existentes.
