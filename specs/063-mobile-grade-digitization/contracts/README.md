# Contratos

El hotfix no agrega ni modifica contratos HTTP. Se mantienen:

- Consulta paginada de revisión por evaluación con parámetro `q`.
- Carga de evidencia por estudiante y evaluación.
- Respuesta de digitalización con preguntas, respuestas esperadas y advertencias.

La única ampliación semántica posible es una advertencia adicional cuando una clave objetiva sea corregida de forma determinista.
