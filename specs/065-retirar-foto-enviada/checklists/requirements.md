# Lista de calidad de requisitos

- [x] El momento exacto de exclusión está definido: respuesta exitosa del servidor.
- [x] La persistencia tras recarga está vinculada a calificaciones existentes.
- [x] El comportamiento de error conserva estudiante y evidencia.
- [x] Los reemplazos permanecen en su flujo dedicado.
- [x] No se modifican datos históricos, contratos ni permisos.
- [x] No quedan decisiones funcionales abiertas.
