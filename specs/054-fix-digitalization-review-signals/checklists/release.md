# Checklist de requisitos para liberación

- [x] ¿La especificación exige distinguir extracción visual y estructuración textual? [Consistencia]
- [x] ¿Queda explícito que las alertas no cambian automáticamente la nota ni la clave? [Integridad]
- [x] ¿Se define cómo tratar alertas asociables y no asociables a preguntas? [Cobertura]
- [x] ¿La aceptación incluye reutilización de extracción e idempotencia? [Recuperación]
- [x] ¿La validación productiva prohíbe confirmar o publicar la nota de prueba? [Seguridad]
